──────────────────────────────────────────────────────────────────────────────
PRIMARY REQUEST FLOW
──────────────────────────────────────────────────────────────────────────────

1. Client requests workflow execution
2. Middleware validates source
3. Registry confirms workflow exists
4. Policy checks request
5. Risk level determined
6. Payload hash created
7. Approval required? If yes -> pending
8. Grant issued after approval
9. Outbox entry created
10. Dispatcher executes once
11. Audit trail written
